# 创意工坊

这里放个人工具项目和待验证的想法。[DoneLog](./DoneLog/README.md)、[每日资讯](./DailyInfo/README.md)和[美食地图](./FoodMap/README.md)均作为独立 Git 子模块接入。DoneLog 源码已迁入本目录；两个手机网页应用已私有发布，并增加首次服务配置页。

全新克隆后运行 `git submodule update --init --recursive`。每日资讯和美食地图的 GitHub 同名仓库尚未创建，完成远端发布前，这两个子模块只能在当前本机使用；DoneLog 重写过的清洁历史也尚未推送到 GitHub。

各项目的当前状态见 [项目进度](./PROJECTS.md)。

项目协作规则见 [AGENTS.md](./AGENTS.md)。每次子项目完成变更时，更新 [项目进度](./PROJECTS.md) 中的描述和最近变更。

## 项目方向

| 想法 | 建议归属 | 第一版可验证的结果 |
| --- | --- | --- |
| 根据工作表生成闹钟，支持手动修改和调班 | [DoneLog 待做功能](./DoneLog/TODO.md) | 导入一份班表，预览日期和提醒时间，确认后生成本地提醒；修改或调班后同步更新提醒，过期提醒自动取消 |
| 每日新闻按兴趣过滤并发邮件 | [每日资讯](./DailyInfo/README.md) | 从明确的新闻源获取内容，按关键词或主题过滤，每天发送一封摘要邮件并避免重复 |
| 演唱会开抢、海航 666 放票提醒 | [每日资讯待做功能](./DailyInfo/TODO.md) | 对指定官方来源检测开售时间或状态变化，有新信息时发送邮件并附原始链接 |
| 网页或截图中的店铺整理、附近美食、沿途找店 | [美食地图](./FoodMap/README.md) | 提取并核对店铺，保存后按当前位置或路线筛选 |

## 当前安排

1. DoneLog 手动班次提醒已通过模拟器验证；取得脱敏班表样例后再做工作表导入。
2. 在每日资讯首次进入时配置 AI 与邮件服务，用真实问题验证来源和送达，再启用每日自动计划。
3. 在美食地图首次进入时配置 AI 与高德服务，用真实帖子截图和手机验证店铺识别、定位与导航。
4. 演唱会与海航放票可建立持续主题并指定来源；具体名单、官方页面及放票规则仍需填写。新闻摘要和短信通知留作后续功能。
